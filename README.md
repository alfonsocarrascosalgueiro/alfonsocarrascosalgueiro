## 🚀 Proyectos destacados

### 🖥️ Homelab Infrastructure — Proxmox & Full Stack Dashboard

**Infraestructura autohospedada con dashboard de administración desarrollado desde cero.**

Proyecto personal que combina desarrollo Full Stack, administración de sistemas Linux, virtualización, autenticación centralizada y monitorización.

**Tecnologías:** React 19, Node.js, Express, Proxmox VE, LXC, Netdata, Nginx Proxy Manager y Authelia.

**Características principales:**
- Dashboard personalizado para centralizar aplicaciones y servicios.
- Infraestructura organizada en siete contenedores LXC.
- Monitorización en tiempo real de CPU, RAM, almacenamiento y red.
- Gráficas históricas con diferentes intervalos temporales.
- Autenticación centralizada con 2FA y permisos por usuario.
- Integración de aplicaciones autohospedadas.
- Interfaz responsive y experiencia PWA para dispositivos móviles.
- Laboratorio de preproducción para desarrollar y validar mejoras.

🔗 **[Ver proyecto, arquitectura y capturas en GitHub](https://github.com/alfonsocarrascosalgueiro/homelab-infrastructure)**

*Repositorio de documentación técnica y capturas. El código y las configuraciones privadas no se publican.*
