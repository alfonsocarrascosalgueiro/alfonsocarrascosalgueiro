## 🚀 Proyectos destacados

### 📅 Generador Automático de Horarios Escolares

Aplicación orientada a automatizar la planificación de horarios académicos, optimizando la distribución de clases, profesores y recursos.

**Aspectos destacados:**
- Automatización de procesos de planificación.
- Resolución de restricciones y optimización de horarios.
- Desarrollo de una solución aplicada a un entorno educativo real.

🔗 [Ver proyecto en GitHub](https://github.com/alfonsocarrascosalgueiro/TFG-Horarios-Escolares)

### 📧 MailBot — Automatización de Correos

Herramienta para automatizar procesos de comunicación mediante correo electrónico.

**Aspectos destacados:**
- Automatización de tareas repetitivas.
- Gestión de procesos de envío de correos.
- Aplicación práctica de herramientas de desarrollo.

🔗 [Ver proyecto en GitHub](https://github.com/alfonsocarrascosalgueiro/MailBot)

### 🖥️ Homelab — Infraestructura y Dashboard Personal

Diseño y administración de un entorno autohospedado basado en **Proxmox VE**, con aplicaciones web, servicios privados y monitorización.

**Tecnologías:** Proxmox, Linux, React, Node.js, Nginx y Authelia.

**Aspectos destacados:**
- Administración de contenedores LXC.
- Desarrollo de un dashboard web personalizado.
- Monitorización de recursos e históricos.
- Autenticación centralizada con doble factor.
- Despliegue y mantenimiento de aplicaciones.

🔒 Proyecto privado. Documentación pública en preparación.

### 📊 Fitness Analytics — Plataforma de Análisis Deportivo

Aplicación web privada para consultar, analizar y visualizar datos de actividades deportivas sincronizados con Garmin Connect.

**Aspectos destacados:**
- Integración y sincronización de datos.
- Visualización de estadísticas y evolución deportiva.
- Gráficas interactivas y filtros temporales.
- Desarrollo de interfaces responsive.

🔒 Proyecto privado. Documentación pública en preparación.
